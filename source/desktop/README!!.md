## ⚙️ VLC Setup

This app uses VLC internally for audio playback. VLC is **not included** in the repository due to its size.

**Steps:**
1. Download **VLC 3.x (64-bit)** from [videolan.org](https://www.videolan.org/vlc)
2. Install it
3. Copy the entire VLC installation folder into the project as `vlc/`

The folder structure should look like this:
```
desktop/vlc/...

```
